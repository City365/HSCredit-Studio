# 节点可插拔改造 — 验收文档

> 本文档定义每个阶段的验收标准, 含:
> - 每个步骤的 API/页面/功能/测试结果
> - 评分 (0-100)
> - 不通过项与处理流程
> - 项目整体验收标准

---

## 验收原则

1. **每阶段验收**: 阶段完成后立即验收, 分数 ≥ 90 才能进入下一阶段
2. **整体验收**: 全部阶段完成后, 整体评分 ≥ 90 才能交付
3. **不通过处理**: 列出具体不通过项 + 严重程度 + 修复负责人 + 重新验收

---

## 评分等级

| 等级 | 分数 | 含义 |
|---|---|---|
| A | 95-100 | 完全满足需求, 实现质量高 |
| B | 90-94 | 满足需求, 有少量可优化点 |
| C | 80-89 | 基本满足, 存在明显改进空间 |
| D | 60-79 | 部分满足, 核心功能可用 |
| F | < 60 | 不满足, 需要重做 |

**门槛**: 阶段验收 ≥ 90, 整体验收 ≥ 90, 否则不通过.
