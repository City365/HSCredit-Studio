## 🎯 项目目标

让节点做到**完全可插拔、可编程、可管理**:

1. **节点管理页面** (`/nodes`): 列表 + 启停 + 编辑 + 删除 + 新增
2. **自定义节点**: 写 Python 代码 + 定义 contract + 沙箱试运行 + 入库生效
3. **输入输出规范**: 在编辑页实时校验 (AST 静态 + 试运行反推)
4. **节点 = 一段 Python 类**: 继承 `BaseNode`, 声明 `NodeContract`, 实现 `run()`

## 🎯 关键决策摘要 (调研后确认)

| 决策 | 方案 | 依据 |
|---|---|---|
| 编辑器 | Monaco (CDN) | Mage.ai / n8n 同款 |
| 代码存储 | PostgreSQL TEXT | 已有 CustomNode 表, 业界共识 |
| 沙箱 v1 | Subprocess + setrlimit + AST 黑名单 | Replit/Code Interpreter 经验 |
| Contract 检测 | AST + 试运行反推混合 | Mage/Prefect 优点结合 |
| 多 worker 同步 | Redis pub/sub | 已有 Redis |
| RBAC | 沿用 super/tenant/analyst 三档 | Phase 6 B28 已有体系 |
| 数据库 | 沿用 PostgreSQL (不引入 SQLite) | 避免多库运维负担 |

详细决策: 见 `00_DECISIONS_PENDING.md`.
